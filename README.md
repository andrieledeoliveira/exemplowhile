# Exercício de Estrutura de Repetição `while` em Java

## Sobre o projeto

Este projeto apresenta um exercício básico sobre a estrutura de repetição `while` em Java.

O programa realiza 5 repetições e exibe os valores de uma variável contadora, iniciando em 0 e finalizando em 4.

## Tecnologias utilizadas

* Java
* `JOptionPane`

## Funcionamento

O programa utiliza uma variável de controle para realizar as repetições. Enquanto a condição estabelecida for verdadeira, uma mensagem é exibida na tela.

A cada repetição, o valor da variável é incrementado até atingir o limite definido.

## Objetivo

Praticar o uso da estrutura de repetição `while` e compreender o funcionamento de condições e contadores em Java.

## Finalidade

Exercício desenvolvido para fins acadêmicos na disciplina de Algoritmos de Programação.
